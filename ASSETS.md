# Assets

- `dist/assets/rinconcito.png`: ilustración generada para esta web a partir de la dirección visual aprobada. Habitación cálida, cama salvia, plantas, manta y pelota; sin personajes ni texto.
- `dist/assets/perrito-estados.png`: ilustración generada para esta web usando la fotografía aportada como referencia del pug. Lámina transparente con poses atento, consentido, juguetón y dormido. El navegador encuadra cada pose; el PNG permanece intacto.
- No se publica la fotografía original ni el rostro de la dueña.
- `dist/assets/patita.svg`: marca geométrica dibujada para esta web.
- Iconos: SVG geométricos incluidos en el HTML.
- Lora y Nunito Sans: fuentes de Google Fonts, autoalojadas; licencias OFL adjuntas.

Las ilustraciones representan al perrito y no se presentan como fotografías reales.
